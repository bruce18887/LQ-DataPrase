# LQ-DataPrase — runtime dependencies (pinned)
#
# POLICY: every entry is pinned with ``==`` to the version that was actually
# installed in the development venv when this file was written. Ranges were
# removed on 2026-10-15 (architecture review P0-5) because the project ships as
# a **PyInstaller binary**: pandas / numpy / matplotlib / Pillow have narrow
# binary-compatibility windows, so a floating version means "the installer you
# build in three months is not the installer you tested", and a user-reported
# bug may be impossible to reproduce. A build that cannot be reproduced is worse
# than a build that is slightly stale.
#
# This also surfaced a real drift: the old line said ``django>=4.2,<7.0`` and
# the docs said "Django 4.2", while the venv had Django 6.0.5 — two major
# versions apart, and nothing in the pipeline could tell.
#
# TO UPDATE: bump the pin here, run ``python manage.py test`` and
# ``npm run test:e2e:affected``, and confirm ``npm run dist:win`` still builds.
# Do not reintroduce ranges.
#
# REMOVED here (both were dead):
#   * ``celery`` — no task was ever defined; see apps/CLAUDE.md. Removed with
#     the whole Celery integration on 2026-10-15 (P0-1).
#   * ``psycopg2-binary`` — every settings profile used SQLite; the PostgreSQL
#     branch was unreachable and the package was not even installed (P0-1b).
