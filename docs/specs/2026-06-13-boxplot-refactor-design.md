# 箱线图重构 + 相关性对比增强 设计文档

**日期**: 2026-06-13
**状态**: 已批准

## 背景

当前箱线图 tab 使用多选参数 + 多图列表展示，与单文件分析 tab 的交互模式不一致。相关性对比 tab 功能较为基础，缺少回归线、分组着色等分析增强。需要统一交互模式并丰富两个 tab 的分析能力。

## 需求来源 (quest.txt)

| # | 需求 | 优先级 |
|---|---|---|
| R1 | 箱线图改为单图模式（一次一个图表） | P0 |
| R2 | 参数显示方式改为和单文件分析一样（ParamSelector） | P0 |
| R3 | 图表布局参考单文件分析的柱状图 | P0 |

## 阶段一：箱线图重构 + 丰富

### 1. 布局变更

**Toolbar**：无分组切换（固定按 Site），加一个 `el-switch` 控制"显示散点叠加"。

**左侧面板**：
- `ParamSelector` 组件（单选 + 上下切换按钮）— 复用现有组件
- 统计数据表格：Count、Mean、Std、Min、Q1、Median、Q3、Max、Outliers 数量

**右侧面板**：
- 顶部 `top-bar`：统计卡片（Min / Q1 / Median / Q3 / Max / Outliers）— 风格同 SingleParamTab 的 StatsSummary
- 主体：单个 `BoxPlotChart` 组件，固定高度

### 2. 图表增强

**分位数标注**：在箱体上通过 `markPoint` 或 `label` 显示 Q1 和 Q3 的具体数值。

**散点叠加（Jitter Plot）**：
- 在箱线图上方叠加原始数据点
- 使用半透明圆形，jitter 随机偏移防止重叠
- 通过 toolbar 的 `el-switch` 控制显示/隐藏

**异常值交互**：
- 异常值点可 hover 显示具体数值
- tooltip 格式：`异常值: {value}`

### 3. 数据层变更

**`useBoxPlot` composable**：
- 参数从 `Ref<string[]>` 改为 `Ref<string>`（单参数）
- 内部 watch 自动触发加载（已有）
- 返回值增加 `stats` 对象（供统计表格和卡片使用）

**API 不变**：后端 `getBoxPlot` 接口仍支持单参数调用，无需修改。

### 4. 组件拆分

| 组件 | 职责 |
|---|---|
| `BoxPlotSection.vue` | 主容器，布局 + 状态管理 |
| `BoxPlotChart.vue` | 图表渲染（已有，增加散点叠加支持） |
| `BoxPlotStatsTable.vue` | 新增，统计详情表格 |
| `ParamSelector.vue` | 复用，参数选择 + 上下切换 |

## 阶段二：相关性对比增强

### 1. 回归线 / 趋势线

散点图上叠加线性回归线：
- 使用最小二乘法拟合
- 显示回归方程 `y = ax + b` 和 R² 值
- 虚线样式，颜色与散点区分

### 2. 分组着色

散点图按 Site 分组着色（当前已按 Site 分 series，确认颜色一致性）。
新增：可切换按 Bin 分组着色。

### 3. 相关性矩阵增强

- 显著性标记：根据 p 值添加 `*` / `**` / `***` 标记
- 显示具体 r 值（已有）+ p 值

### 4. 参数筛选

矩阵模式下新增参数多选器：
- 默认全选含 Limit 的测试项
- 可取消选择部分参数
- 仅计算选中参数的相关性矩阵
