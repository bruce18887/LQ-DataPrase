## 🚫 不可实现项示例

### 🚫-1: 鱼骨图自动生成
**原因**: 鱼骨图是人工团队讨论和领域经验驱动的分析工具。自动生成需要理解生产上下文和具备半导体失效机理因果推理能力（LLM 级别的领域 AI）

**替代方案**: 系统输出 Pareto 分析 + 各维度统计对比（按 Site/按 Batch/按时间/按参数），为工程师的人工鱼骨图分析提供数据输入

### 🚫-4: 设备利用率（OEE/MTTR）
**原因**: 这些指标要求的数据源是设备运行/停机/维护日志（需要 MES 或 CIM 系统）、生产节拍和计划（需要 ERP/APS 系统）、维修工单和维修时间（需要 EAM/CMMS 系统）

**替代方案**: 系统可以在有了 Multi-site Efficiency 和 Test Time 数据后，输出"测试站利用率估算"（Test Time 占比）

## 🔄 维护指南

### 更新任务状态
当功能开发完成后，在 `RoadmapPage.vue` 中更新状态：

```typescript
// 从待开发改为已完成
{
  id: 'TODO-01',
  status: '✅',  // 原来是 '📝'
  task: '相关性矩阵批量 API',
  files: 'apps/analysis/views.py',
  section: '§3.2 / §7.3'
}

// 从待开发改为部分完成
{
  id: 'TODO-02',
  status: '⚠️',  // 原来是 '📝'
  task: 'Pareto 图表组件',
  files: 'frontend/src/pages/analysis/components/ParetoChart.vue',
  section: '§4.2 / §7.5'
}
```

### 添加新任务
在对应优先级数组中添加新任务：

```typescript
const p0Tasks = ref<Task[]>([
  // ... 现有任务
  {
    id: 'TODO-27',
    status: '📝',
    task: '新功能描述',
    files: '涉及的文件路径',
    section: '对应章节'
  }
])
```
