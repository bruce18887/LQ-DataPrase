## 🚀 启动步骤

### 方法一：启动前端开发服务器

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖（如果还没安装）
npm install

# 3. 启动开发服务器
npm run dev
```

服务器启动后，访问: `http://localhost:5173/roadmap`

### 方法二：启动完整项目

```bash
# 1. 启动后端（在项目根目录）
python manage.py runserver

# 2. 启动前端（新终端窗口）
cd frontend
npm run dev
```

然后访问前端地址并登录系统。

## 🔧 常见问题

### Q1: 页面显示空白？
**A**: 检查以下几点：
- 前端服务器是否正常启动
- 浏览器控制台是否有错误
- 是否已登录系统
- 路由配置是否正确

### Q2: 导航菜单没有"功能路线图"？
**A**: 
- 确认 `MainLayout.vue` 已更新
- 清除浏览器缓存
- 重启前端开发服务器

### Q3: 如何更新任务状态？
**A**: 
编辑 `frontend/src/pages/roadmap/RoadmapPage.vue`，找到对应任务，修改 `status` 字段：
```typescript
{
  id: 'TODO-01',
  status: '✅',  // 改为已完成
  // ...
}
```

### Q4: 如何添加新任务？
**A**: 
在对应优先级数组中添加新对象：
```typescript
const p0Tasks = ref<Task[]>([
  // 现有任务...
  {
    id: 'TODO-27',
    status: '📝',
    task: '新任务描述',
    files: '文件路径',
    section: '章节'
  }
])
```
