## 📦 数据结构

### Task 接口
```typescript
interface Task {
  id: string        // 任务编号: TODO-01 ~ TODO-26
  status: string    // 状态: ✅/⚠️/📝/🚫
  task: string      // 任务描述
  files: string     // 涉及文件路径
  section: string   // 对应文档章节
}
```

### BlockedItem 接口
```typescript
interface BlockedItem {
  id: string        // 编号: 🚫-1 ~ 🚫-10
  title: string     // 标题
  reason: string    // 不可实现原因
  alternative: string  // 替代方案
}
```

### 数据示例
```typescript

```

## 🔄 数据流

### 页面渲染流程
```
1. 组件挂载
   ↓
2. 加载任务数据 (p0Tasks, p1Tasks, p2Tasks, blockedItems)
   ↓
3. 计算统计数据 (stats computed)
   ↓
4. 计算完成率 (completionRate computed)
   ↓
5. 确定进度条颜色 (progressColor computed)
   ↓
6. 渲染页面元素
   ↓
7. 用户交互 (展开折叠面板等)
```

### 状态更新流程
```
开发完成某功能
   ↓
修改对应任务的 status 字段
   ↓
stats 自动重新计算
   ↓
completionRate 自动更新
   ↓
progressColor 自动变化
   ↓
页面自动刷新显示
```

## 🎯 功能模块

### 1. 统计模块
- **功能**: 计算各状态任务数量
- **输入**: 任务列表数组
- **输出**: 统计对象
- **更新**: 响应式自动更新

### 2. 进度模块
- **功能**: 计算完成百分比
- **算法**: (已完成 + 部分完成×0.5) / 总数 × 100%
- **颜色**: ≥80%绿色, ≥50%橙色, <50%红色

### 3. 任务展示模块
- **功能**: 分优先级展示任务
- **分组**: P0/P1/P2
- **字段**: 编号/状态/描述/文件/章节

### 4. 不可实现项模块
- **功能**: 展示不可实现项及原因
- **交互**: 折叠面板
- **内容**: 原因 + 替代方案
