## 🚀 使用方法

1. 启动前端开发服务器：
   ```bash
   cd frontend
   npm run dev
   ```

2. 登录系统后，在左侧导航菜单中点击"功能路线图"

3. 查看各优先级的任务列表和实现状态

4. 点击不可实现项可展开查看详细说明

## 🔄 后续维护

当功能开发完成后，需要更新页面中的状态标识：
- 将 `status: '📝'` 改为 `status: '✅'`（已完成）
- 或改为 `status: '⚠️'`（部分完成）

示例：
```typescript
{
  id: 'TODO-01',
  status: '✅',  // 从 '📝' 改为 '✅'
  task: '相关性矩阵批量 API - analysis:correlation_matrix',
  files: 'apps/analysis/views.py',
  section: '§3.2 / §7.3'
}
```
