# 02 快速上手

六步走完「安装 → 第一张良率结论」。

## 第 1 步 · 安装与启动

1. 运行安装程序（或免安装目录中的主程序），桌面生成 LQ-DataPrase 快捷方式。
2. 双击启动：Electron 壳自动拉起内嵌 Django 后端并等待健康探针就绪，**无需手动装 Python、Node 或数据库**。
3. 窗口打开即登录页；后端异常时会显示诊断页而不是黑窗口。

<div class="intro-note">单机离线形态：数据与计算都在本机，不依赖外网服务。</div>

## 第 2 步 · 登录

1. 输入账号密码登录；账号由管理员在「用户管理」创建与维护（见 [§9](./09-admin) 的可操作复刻）。
2. 连续输错密码会触发登录限流，剩余尝试次数会记录在操作审计中。
3. 登录后顶栏显示当前账号与角色，右上角可切换浅色 / 夜间主题。

## 第 3 步 · 上传数据

1. 进入「数据管理 → 文件列表」，点击 **上传文件**（或直接拖拽 CSV / ZIP 到列表区）。
2. ZIP 批量包自动解析为批次；单 CSV 自动识别阶段（CP / FT）、格式与测试程序。
3. 需要按批分析时，勾选多个文件点 **组合为批次**（新建需 ≥2 个文件，追加 1 个即可）。

<div class="intro-note">[§4](./04-data) 的文件列表复刻可以直接试：搜索、勾选、展开行、组合批次对话框都在里面。</div>

## 第 4 步 · 看仪表板

1. 「仪表板 → 单文件分析」选择刚上传的文件。
2. KPI 带给出总记录 / Pass / Fail / Yield / UPH / 测试时长；告警带自动提示良率、CPK、Site 差异问题。
3. 切到「批次良率」看整批视角：阶段胶囊全局过滤、QA 校验条、Bin × Site 矩阵定位问题 Site。

## 第 5 步 · 深入分析

1. 「数据分析 → 单文件分析」选参数：直方图 + KDE + 规格限 + CPK 分级一屏给出。
2. 在直方图上**按住左键拖框**可框选子集，右键「新建子集直方图」看局部统计（[§5](./05-analysis) 演示可试）。
3. CP 文件切「晶圆图」看失效空间分布；多批对比切「多文件分析」；找联动关系切「相关性对比」。

## 第 6 步 · 导出与分享

1. 「数据管理 → 导出工具」：选参数 → 图表配置 → 批量导出 Excel / PPT，后台作业带进度 chip。
2. 单文件表格可在「查看数据」直接导出 Excel（后台作业）/ CSV（同步）。
3. Gage Summary / Buyoff Form / 权重曲线页各自一键导出 xlsx。
