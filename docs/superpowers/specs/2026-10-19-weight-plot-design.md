# 权重画图功能设计

- 日期：2026-10-19
- 状态：待评审
- 输入样例：`data/Trim_Weight_Site2.csv`
- 关联工程：DataPrase-ExcelAddin（Excel-DNA，net462）

## 1. 背景与目标

样例文件是 C 风格声明列表，共 56 条：

```text
double NAME[长度] = {数值,数值,...};
```

实测结构：

- 56 条声明，14 个不同测试项，每个重复 4 次；
- 数组长度只有 4 / 8 / 16 / 32 / 64 五种，最大 64；
- 同名声明在不同块中重复出现，数值略有差异。

目标：点击 Ribbon 按钮选一个权重 CSV，在当前工作簿生成一张工作表：
左侧为权重曲线图，右侧为同一批数据的数值表；图例可按测试项开关；
可一键计算并显示同名测试项的逐点均值曲线。

## 2. 已确认的口径

| 项目 | 决定 |
|---|---|
| 表格顺序 | 按测试项分组；**组序 = 测试项在文件中首次出现的顺序**；组内按出现顺序 `_1.._4` |
| 图例开关 | 每个测试项 1 个，共 14 个；一次开关该名称下的 4 条曲线 |
| 均值 | 逐点均值：同名 4 条在同一 code 上求平均，每项 1 条 `_Avg` 曲线 |
| 均值按钮 | 放在表格上方（第 1 行） |
| 输入入口 | Ribbon「权重画图」+ 文件选择框，每次选一个 CSV |
| 输出位置 | 当前工作簿的新工作表，左图右表同表 |
| 图表类型 | XY 散点直线图，无数据点 |
| X 轴 | 固定 0..（文件中最大数组长度 - 1），本样例为 0..63 |
| Y 轴 | 由 Excel 按当前可见系列自动缩放 |

## 3. 输入契约与解析

### 3.1 解析规则

新增 Core 侧解析器（零 Excel 依赖）：

- 识别形如 `double 名称[声明长度] = {数值列表};` 的声明，允许换行、空白；
- 忽略文件中的其他行与空行；
- 数值按 `InvariantCulture` 解析，支持小数与科学计数法；
- 名称保留原样（区分大小写）。

### 3.2 校验

- 无任何合法声明 → 报错「文件中没有找到 double 权重声明」；
- 声明长度与实际数值个数不一致 → 报错并带行号；
- 数值无法解析 → 报错并带行号；
- 解析失败时不创建/不修改任何工作表。

### 3.3 命名

- 某名称只出现 1 次：保持原名；
- 出现 N 次（本样例 N=4）：全部加序号，`名称_1 .. 名称_N`；
- 均值行名称：`名称_Avg`。

### 3.4 均值定义

对每个测试项：

- 组内声明长度一致时，逐点对 4 条求算术平均；
- 若将来出现长度不一致，均值长度为组内最大长度，每个 code 只对该位置有值的声明求平均；该位置无值则留空；
- 均值在点击「均值」按钮时才计算并写入表格。

## 4. 输出工作表

### 4.1 生命周期

- 工作表名：`权重图_<文件名去扩展名>`（如 `权重图_Trim_Weight_Site2`）；
- 名称中的非法字符 `[]:*?/\` 替换为 `_`，总长截断到 31 个字符；
- 同名工作表已存在 → 删除后重建（该表是生成物，不做内容保留）；
- 重新画图后状态复位：14 组全开、均值关闭。

### 4.2 几何布局

| 区域 | 位置 |
|---|---|
| 图表 | 锚定 `A1:O45`（按该区域实际几何取 Left/Top/Width/Height） |
| 「均值」按钮 | `Q1:R1` |
| 表头 | 第 3 行 |
| 数据 | 从第 4 行开始，Q..CE 列 |

列定义：

| 列 | 内容 |
|---|---|
| Q | 显示：每个测试项一个复选框，位于该组首行 |
| R | 原序号：该声明在原文件中的序号（1..56） |
| S | 系列名：`名称_1..N`，均值行 `名称_Avg` |
| T..CE | code 0..63 的数值 |

### 4.3 行结构

按测试项分组，每组 5 行：

```text
名称_1     ← Q 列复选框（组首行）
名称_2
名称_3
名称_4
名称_Avg   ← 初始隐藏；点「均值」后计算、写入并展开
```

- 14 组 × 5 = 70 行；初始可见 56 行；
- 均值行初始 `Hidden = true`；点击「均值」时计算、写入、取消隐藏；
- 复选框与按钮设 `Placement = xlMove`，均值行展开/收起时随单元格移动；
- 组底色交替（极浅灰），测试项名称文字使用该组在图表中的基色；
- 数值保留原始精度；code 列使用窄列宽，允许横向滚动；
- 不冻结窗格。

## 5. 图表

### 5.1 结构与数据源

- 工作表内一个 ChartObject，名称固定 `DpWtChart`；
- 类型：`xlXYScatterLinesNoMarkers`；
- 系列顺序与表格组序一致；每组 4 条原始曲线；均值可见时，每组追加 1 条均值曲线；
- 每条系列的 X 值取表头行对应的 `0..N-1`，Y 值取该行同样长度的单元格区域；
- 短数组只取自身长度，不使用空单元格补齐；
- 开关或均值变化时**只重建图表系列**，不重建图表对象，保留位置与用户调整。

### 5.2 轴

- X 轴：`MinimumScale = 0`，`MaximumScale = 最大数组长度 - 1`（本样例 63）；
- Y 轴：不固定最小/最大，由 Excel 对当前可见系列自动缩放；
- 坐标轴标题：`Code` / `Weight`；
- 图表标题包含文件名。

### 5.3 颜色与样式

- 每个测试项分配一个基色（14 色表）；
- 组内 4 条使用同色系的 4 个变体（明暗/色相偏移），满足「同名不同颜色」；
- 均值线：深灰粗虚线，与原始曲线区分；
- 图例置底部，字号约 7pt；线条宽度约 1–1.25pt；
- 全部 56 条同时可见时允许密集，通过分组开关收敛。

## 6. 控件、命令与状态

命令均注册为 `[ExcelCommand]`，供 Form Control 的 OnAction 调用。

| 控件 | 名称 | OnAction | 行为 |
|---|---|---|---|
| 组复选框 ×14 | `DpWtShow0..13` | `DpWeightToggle` | 读取 14 个复选框状态，重建图表系列 |
| 均值按钮 | `DpWtMean` | `DpWeightMean` | 均值行隐藏时：计算→写入→展开→添加均值系列→标题「隐藏均值」；可见时：清空→隐藏→删除均值系列→标题「均值」 |

规则：

- 未勾选的组：表格行保留，图中不出现其 4 条原始曲线与均值曲线；
- 均值可见时，只有勾选组的均值曲线进入图表；
- 状态来源：复选框值 + 均值行是否可见；不额外写状态格；
- 点击控件时用 `ExcelStateGuard` 关闭刷新与自动重算；
- 图表被用户删除时，提示重新执行「权重画图」。

## 7. 入口与错误处理

- Ribbon：「处理」组新增大按钮「权重画图」，回调 `OnWeightPlot`；
- 文件框过滤器：`权重 CSV (*.csv)|*.csv|所有文件 (*.*)|*.*`；取消则不做任何事；
- 要求存在活动工作簿；没有则提示「请先打开一个工作簿」；
- 解析失败、工作表操作失败：交互模式弹 MessageBox；非交互模式（自动化）直接抛出，沿用现有 `Actions.Run` 口径；
- 成功后可提示：工作表名、测试项数、系列数、code 数。

## 8. 验证方案

### 8.1 Core 单元测试（NUnitLite）

- 解析真实样例：56 条声明、14 名称、最大长度 64；
- 分组与命名：14 组 × 4 条，`_1.._4`，组序等于首次出现顺序；
- 均值：逐点正确；长度不一致时只对可用值求平均；
- 错误：声明长度不符、非法数值、无声明、杂行忽略。

### 8.2 加载项实机自检

新增隐藏函数 `DpSelfCheckWeight(csvPath)`，在临时工作簿上真实执行建表/建图，回报并断言：

- 工作表名正确；
- `groups=14`、`rawRows=56`、`meanRows=14(hidden)`、`chartSeries=56`、`checkboxes=14`；
- X 轴最大值 = 63；
- 关闭第 1 组后 `chartSeries=52`；重新打开后恢复 `chartSeries=56`；
- 打开均值后 `chartSeries=70`（56 条原始 + 14 条均值）、均值行可见；
- 再关闭均值后回到 `chartSeries=56`、均值行隐藏；
- 不保存临时工作簿，结束后关闭。

`build/verify-installed.ps1` 增加 `-WeightCsv` 参数，调用该函数并做同样的文本断言。

### 8.3 肉眼验证

- 用真实样例生成一次，导出图表 PNG，检查颜色、图例、轴、均值线；
- 在真实 Excel 中点击 1 个组开关与「均值」，确认无错位、无卡顿。

## 11. 风险与待实测项

1. 56 条系列的建图/开关重建耗时，需在实机上量一次；若过慢，改为按组缓存系列或分批添加。
2. XY 散点图在 Excel 对象模型中 X 轴的访问路径（`xlCategory` / `xlValue`）需在实现时用临时簿验证。
3. Form Control 在隐藏行展开时的位移依赖 `Placement`，自检需读回复选框 Top 验证。
4. 14 色在全部组同时可见时区分度有限；先按色系方案实现，肉眼确认后再调色板。
